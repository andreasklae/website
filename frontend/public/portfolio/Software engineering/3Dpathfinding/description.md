## Description (en)

I am developing a research project with two other students that benchmarks multiple
pathfinding algorithms in procedurally generated 3D mazes. The project
combines both the **engineering side** (maze generation, algorithm
implementation, batch runs) and the **analytical side** (data
visualization, statistical evaluation).

A benchmarking and visualization framework for 3D pathfinding algorithms
on voxel-based mazes.\
Built with Python, NumPy, Plotly, and pathfinding3d, it generates
asteroid-field inspired environments, runs A*, Dijkstra, Breadth-First,
and Theta*, and records performance metrics across distance regimes.
Results are stored in CSV for reproducibility and explored in Jupyter
notebooks with pandas, matplotlib, seaborn, and SciPy.

Features include:\
- Procedural 3D maze generation with organic obstacle fields\
- Start/end placement with snapping to walkable cells\
- Multiple algorithms (A*, Dijkstra, Breadth-First, Theta*) with
diagonal movement\
- Interactive Plotly HTML visualization of obstacles and paths\
- Batch runner producing CSV metrics across distance categories\
- Jupyter notebook analysis with charts, violin plots, and summary
statistics

## Description (no)

Jeg utvikler et forskningsprosjekt sammen med to med-studenter som tester og sammenligner flere
pathfinding-algoritmer i prosedyregenererte 3D-labyrinter. Prosjektet
kombinerer både **den tekniske delen** (generering av labyrinter,
algoritmer, batch-kjøring) og **den analytiske delen**
(datavisualisering og statistisk evaluering).

Et rammeverk for benchmarking og visualisering av
3D-pathfinding-algoritmer på voxel-baserte labyrinter.\
Bygget med Python, NumPy, Plotly og pathfinding3d, genererer det
asteroidefelt-lignende miljøer, kjører A*, Dijkstra, Breadth-First og
Theta*, og lagrer ytelsesdata på tvers av avstandskategorier.
Resultatene lagres i CSV for reproduserbarhet og analyseres i
Jupyter-notatbøker med pandas, matplotlib, seaborn og SciPy.

Funksjoner inkluderer:\
- Prosedyregenererte 3D-labyrinter med organiske hindringsfelt\
- Start- og sluttpunkter plassert og justert til gangbare celler\
- Flere algoritmer (A*, Dijkstra, Breadth-First, Theta*) med
diagonalbevegelse\
- Interaktiv Plotly HTML-visualisering av hindringer og ruter\
- Batch-kjøring som produserer CSV-data på tvers av avstandskategorier\
- Analyse i Jupyter-notatbok med grafer, violin-plott og
sammendragstatistikk
